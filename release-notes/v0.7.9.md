<h3 id="cn-v0.7.9">🔌 v0.7.9：移除设置卡片指向上游仓库的链接</h3>

兼容 DeepSeek Harness `0.2.1-rc.4`；支持范围 `>=0.1.7-rc.1 <0.3.0` 不变。
这一版只做一处清理：「局域网访问」设置卡的更新状态条上，GitHub、更新日志、反馈 Issue 三个链接全部移除。

- 原因：三个链接硬编码指向上游仓库 `idoall/dsh-lan-guard`。本 fork（`liuke101/dsh-LAN`）包含上游没有的选择器修复，使用者点开这些入口看到的版本说明与实际安装的插件不符，容易造成误导。
- 更新状态条保留版本徽章与「检查更新」按钮；版本检查、升级命令复制等行为不变。

<h3>升级</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@0.7.9
```
重启 DSH 一次即生效。

<h3 id="en-v0.7.9">🔌 v0.7.9: removes the settings-card links to the upstream repository</h3>

Compatible with DeepSeek Harness `0.2.1-rc.4`; the supported range `>=0.1.7-rc.1 <0.3.0` is unchanged.
One cleanup in this release: the GitHub, changelog, and issue links are gone from the update chip on the LAN-access settings card.

- Why: all three links were hardcoded to the upstream repository `idoall/dsh-lan-guard`. This fork (`liuke101/dsh-LAN`) carries picker fixes upstream does not have, so those links took readers to release notes that do not match the installed plugin.
- The update chip keeps the version badge and the check-for-updates button; update detection and the copyable upgrade command are unchanged.

<h3>Upgrade</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@0.7.9
```
Restart DSH once.
